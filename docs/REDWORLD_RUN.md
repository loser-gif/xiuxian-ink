# 红尘单局流程 · v72 实施稿

先在纸上走完，再接系统。参考过开源文字游戏 [A Dark Room](https://github.com/doublespeakgames/adarkroom) 的行动与资源反馈；本项目继续使用已有静态脚本，不引入框架或复制外部代码。

1. 炼气时到云岳坊。巷尾人人能租，先显示首季租金。把自备药材上架，选低／平／高价。开季前看到具体货、进账 A–B、租金、风险和光阴。经营使用一次游历的时间（3 × 境界 T，再按既有时间倍率）；高境的一季不是三个月。
2. 可以关卷去修炼，没有离线售货或离线欠租。回铺时，过期租约先续本季，现金不足可明确选择交回铺面。旧买断铺面保留免租；旧租约保留剩余期限。休市不自动推进时间，也不改修为或寿元。
3. 普通季度按货物和定价卖出；自备货成本只显示参考价，不能伪称现金支出。可从坊市按实际市价进货，账本分别写进货支出、售货收入、赊免货款、租金和现金净额。高于本季上限的整件货不卖，可随时取回。不能售本命法宝或神器。
4. 良心季度收取预计货款的下半，留下赊免账，不会以后偷偷补款绕过上限；口碑上升，回头客带来消息和作保。掺假季度收满上限，口碑大跌、正邪小跌，魔基跌得更多；随后处理苦主、查铺和仇怨。道基改变服务与故事，不增加上限。
5. 口碑 20 可迁街中或开第二间，40 且正邪 > −20 可去坊市口。米婆信任且仍在世时可当面让铺；回头客作保可租街中。总共三间。开分店按钮先写明掌柜卷货、口碑连亏和钱十三抢客，再扣首季租金。钱十三死后不再出场。
6. 一次亏损不扣修为／寿元／道基。不能付租时收回铺面、未售货返还，租金记成人情债，口碑减半。只可从巷尾小摊重来；连续三个诚实季度或还清欠账恢复。良心旧客允许一次免首季租金重开。
7. 开铺之外也可施药、留夜、去疫镇。三类善事合计三次立祠，六次塑像；均无属性奖励。道果来自诚实开季、善事、主动接下凡人因果和香火庇佑。正邪独立，救人 +3，杀害回响人物 −12，口碑不随之变动。
8. 祠立后每过十二个实际年可领一次：心境 +2，或留一道免轻伤的庇佑。庇佑不叠层，不免重伤。守祠两次后有求情，再两次后邪修砸祠；可花一季与明示灵石守住，或无耗时放弃。祠毁道果冻结，花一季与明示灵石重修后恢复；香火冷却不重置。
9. 化神圆满瓶颈、道果 ≥24 且正邪 ≥20，才有「不渡，留在人间」与渡劫并列。没有隐藏战力、寿元、破境奖励。题跋为「入世修行，终得正果。世人称红尘仙。」下一世红尘字段归零。

纸上走查：六次行善得 12 果、十二个诚实季度得 12 果，正邪至少 30，可达到终门门槛；中途仍需完成原来的修炼。连续掺假拿即时收入，却得不到道果且承担追债；仍可飞升。三店高价遇口碑崩落可零收入，但明示的季度区间含零。纯修炼者不进铺，原平衡不受影响。破产后返货、免首季摊位与三次诚实经营提供恢复路径；没有必须靠额外丹药才能解除的死锁。
