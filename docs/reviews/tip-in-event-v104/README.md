# v104 · 同纸揭笺

桌面 Chromium 视口验收。未做 iPhone Safari 真机。

缓存 `moxian-v104`，`SAVE_V` 仍为 16。玩法、奇遇正文、选项和存档格式未改。

## 对照

v103 的奇遇是一块压在深色罩上的横卷：底纸被压暗，对手信息还套着内框。v104 改成同一张宣纸上揭开的一笺。

- 遮罩只剩很淡的墨晕，主卷的字和纸色还在。
- 笺面用主卷的纸色，边是 1px 淡墨。没有木轴，也没有横卷展开。
- 对手写成朱砂小字，名字旁边盖一枚「敌」。不再套第二层框。
- 右侧仍是朱签。字随这条奇遇，狼这一则是「奇」。
- 揭开时纸从顶边往下展开，不是整块淡出。简动效会缩短，系统减少动态时直接到达。
- 夜墨下笺面跟滤过后的深纸齐色，正文改淡墨，避免深字落在深纸上。
