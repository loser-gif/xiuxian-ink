# v67 寄拍修复验收

来源：正常完整新局的 [issue #47](https://github.com/loser-gif/xiuxian-ink/issues/47)。A4 已于 v66 玩至沈观澜 580 岁飞升；本目录是其后独立进行的定向回归，不冒充正常游玩。

## 修复边界

- 寄拍结算调用发生在结束回调声明之后，最后一件可散场；去掉 Promise 的 async executor。
- 每件落槌立即保存，成交价与领先者刷新。原 18% 抽成和价格公式不变，纠正原“一成二”的说明。
- 尚未落槌的寄拍物记在 `auc.pending`；续卷退回一次。未登楼便错过整场时也退回，拒绝覆盖已有寄拍物。
- SAVE_V 保持 14。只补可选字段，旧档无此字段不变。v66 已经丢掉记录的历史寄拍无法凭空推断物品和金额；没有自动补偿旧损失。
