# v93 美术生成说明

工具：内置 image_gen.imagegen。参考：用户已确认的桌面画卷概念图。以下为各次生成要求的归纳，不是逐字 API 日志。

1. 山水背景：移除参考图全部文字、数值、按钮、卷轴和境界墨圈，保留温暖宣纸、水墨山水、左侧松崖、下方湖面、右下亭台和红叶、右上山峦与红日；中央留白适合承载 UI。
2. 空白卷轴：透明外部背景，方形空白宣纸卷面；象牙色织锦上下卷杆、棕色轴头、窄绢边；不带文字或山水。用于可伸缩九宫格边框。
3. 装饰图集：透明背景，左半为淡墨环形笔触，右半为稀疏秋日枫枝；彼此不重叠，不带字，用于境界与卷内页眉。

原始 PNG 已移到 D 盘输出目录；运行版只进行了格式与压缩转换，没有通过脚本重绘图片。生成内容用于游戏装饰，所有可交互 UI 与可读文本仍由 HTML/CSS 渲染。
