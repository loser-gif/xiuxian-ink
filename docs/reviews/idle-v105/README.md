## 怎么进

卷首底栏仍是存档、图鉴、日缘、试炼。其下单独居中一枚笔触：**闲录** / 小字「墨童」。点开是同一张宣纸上的一层，左下「收卷」回到卷首。不进正传主界面。

## 这一层

- 墨童是一滴不规则的墨，旁边一两笔干痕，脸只留极小的纸孔。人小，纸空。
- 点墨得墨气。置办在左，心法在右。窄屏用页签切换，底栏点墨固定。
- 够了可以「再落一墨」。本世置办、心法、墨气收回，道印留下。
- 离开再开，进度还在。正传那一卷不动。
