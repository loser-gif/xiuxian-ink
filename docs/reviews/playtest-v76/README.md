# v76 试玩

线上 [纸上仙途](https://loser-gif.github.io/xiuxian-ink/?v=76)，`EXPECT` 与 `sw.js` 都是 `moxian-v76`。v76 是玩家改过的叙事原文（五十九处），公告写明玩法未动，`SAVE_V` 仍是 16。下面界面结论按 v76 的句子来。v75 只补了桌面布局，v76 没有再量一遍。

没有改存档，没有改随机数，没有跳境界。点的是页面上的按钮。

## 结论

可以再做一轮桌面打磨。这两局里没有玩家会被卡住的软锁，也没有对不上的物价。界面没有走到飞升：一次死在化神冲渡劫失败之后，一次死在元婴，寿元先尽。

模拟（不是这两局）里，三灵根 `balanced` 全体用时中位 82.5 分钟，落在 80–90。见文末。

## 没走到的

- 飞升。两局都是寿元先尽。主局差在渡劫那一掷没有丹。
- 听雨楼寄拍。灯笼挂过，人没在开楼时赶到。最后一件散场这次没覆盖。v67 的寄拍收口没有在这几局里再点一遍。
- 散修看到「宗门来信」。两局都没进京城开仓那一选。`js/tianxia.js` 里私动修士储粮的结算仍写「宗门来信」，不看成没成过宗。这局里没复现。

## 布局（v75，v76 没重测）

v75 当时的线上页，1440×900，并抽过 1280×720。

- 卷首行藏在两档里都在画面里。见 `main-early-1440.jpg`、`main-early-1280.jpg`。行藏条数还少，没有堆到要在笺里滚动的程度。
- 地图能点、能走。1440 卷宽 1174（画布 3167），1280 卷宽仍是 1174（画布 2331，高 502）。没有窄到 600 以下。1280 上卷宽不跟窗口一起收，地点笺贴在右缘，空位窄。见 `map-1440.jpg`、`map-1280.jpg`。
- 古修洞府正文色 `rgb(27, 24, 20)`，句子是「石门高三丈，门上符文如蛇游走。指尖一触，符文便缠了上来。」深墨，能读。见 `cave-1440.jpg`。
