# v106 · 同纸再揭

桌面 Chromium 视口验收。未做 iPhone Safari 真机。

缓存 `moxian-v106`，`SAVE_V` 仍为 16。正传存档键未改。闲录只写 `moxian-idle-v1`。

对照是 v105 审计（`docs/reviews/audit-v105/REPORT.md`）。这一版把还架在木轴和深罩上的几张纸，收到和奇遇一样的同纸揭笺：淡罩、淡边、直角。

## 改了什么

- 试炼说明和问询去掉 9px 木轴，实色深罩换成很淡的墨晕。笺面与卷首同一张纸，角上留一枚「问」。试炼自己的朱印还在。
- 存档、图鉴、行囊不再是压暗的圆角浮卡。窄屏上缘是直角，宽屏也是淡边纸笺。
- 出身、拜山、道基、此生所求从深褐仪式改成淡纸深字。落定按钮是浓墨，不再是深底上的淡笔。
- 闲录铺一层透出远山的纸，卷首题额和底栏在这一层打开时隐去，免得压住列表。夜墨里墨童的 `color` / 孔 `fill` 写成固定墨色，不再跟着 `--ink` / `--paper` 反白。
- 续卷副题改成实色浓墨，笔触也改淡，灰字不再落在灰笔上。
- 矮屏 390×700 上，闲录笔触不再压住右下的声。官网顶栏「立刻试玩」的墨形右缘留出空白。

## 还留着

斗法、破境、拍卖、终卷仍是 v51 的实色罩。地图和秘境仍是整页换纸。700 到 999 宽的音量条仍不常驻。闲录打开后，键盘焦点还停在卷首那枚按钮上。
