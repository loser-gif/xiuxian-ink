# v94 主卷动态壁纸验收

2026-10-26。用户要求主游戏界面像主菜单一样成为动态山水。

## 实现

- 复用 Wallpaper 既有雾纹生成、湖光纹理与舟鹤 SVG，新增主卷专用的低分辨率流雾画布；不新增图片或运行依赖。
- 湖面缓慢起伏，小舟漂行并轻摇，双鹤掠过远景；卷边枫枝小幅摆动，暖光缓慢变化。动画位于背景层，正文、卷轴和操作区不随之位移。
- 流雾绘制频率上限约 20fps，位图为视口四分之一分辨率且宽度最多 512 像素。440×956 DPR3 下仍为 110×239。
- 离开主卷或页面隐藏时暂停；简动效、自动低帧率降级、系统减少动态均停止主卷绘制与装饰动画。恢复设置或回到游戏后继续。
- GitHub 方案检查：[Vanta](https://github.com/tengbao/vanta) 是成熟的动态背景方案，但采用 three.js/p5.js；本游戏已有适合水墨风格的实现，所以直接复用现有模块。

## 验证

[24 项动态与交互检查](checks.json) 全部通过，无页面异常。覆盖画布像素变化、舟与枝的变换、正文几何稳定、简动效、系统减少动态、自动降级、隐藏处理、回卷首与续卷、昼夜和手机入口。

视口：1440×900、1280×720、440×956、375×812、844×390，各检查昼夜；另检查 440×956 DPR3 位图大小。隐藏处理通过临时覆盖 document.hidden 并分发 visibilitychange 测试，不冒充真机切后台测试。Windows Edge/Chromium 验收，尚无 iOS Safari 真机结果。

语法检查、存档迁移/往返、日志回归、版本一致性和字体覆盖审计通过。只改表现，未修改数值与存档格式，因此没有重复平衡模拟。
